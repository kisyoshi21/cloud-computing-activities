# Amazon Web Services (AWS) Research

## Brief Overview
AWS is the world's most comprehensive and broadly adopted cloud platform, offering over 200 fully featured services from data centers globally.

## Global Infrastructure
AWS operates through Availability Zones (AZs) grouped into Regions worldwide, providing high availability, fault tolerance, and low latency.

## Cloud Management Console
The AWS Management Console provides a secure web-based interface to manage, monitor, and configure all AWS resources, billing, and security settings.

## Four (4) Core Services
1. **Amazon EC2:** Provides resizable compute capacity in the cloud for running applications.
2. **Amazon S3:** Offers scalable object storage designed to store and retrieve any amount of data.
3. **Amazon RDS:** A managed relational database service supporting engines like MySQL, PostgreSQL, and SQL Server.
4. **AWS IAM:** Securely manages access to AWS services and resources through fine-grained permissions.

## Three (3) Advantages
* Broadest and deepest set of globally deployed operational services.
* Massive global infrastructure with high reliability and a mature partner ecosystem.
* Continuous innovation in emerging fields like serverless computing, containers, and machine learning.

## Typical Enterprise Use Cases
* Scalable web applications and enterprise resource planning (ERP) systems.
* Big data analytics, massive data lakes, and secure cloud migration architectures.
