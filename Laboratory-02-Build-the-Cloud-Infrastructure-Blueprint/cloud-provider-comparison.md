# Cloud Provider Comparison Report

## Core Infrastructure Services Comparison Table

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Google Compute Engine (GCE) |
| **Storage** | Amazon S3 | Azure Blob Storage | Google Cloud Storage (GCS) |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | Google Virtual Private Cloud (VPC) |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID (Azure AD) | Google Cloud IAM |

## Guide Questions

1. **Which cloud provider offers the broadest range of services? Explain your answer.**  
   AWS offers the broadest range of services because of its early entry into the market and continuous rapid innovation. It provides hundreds of fully featured services spanning traditional infrastructure, serverless computing, machine learning, and Internet of Things (IoT).

2. **Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**  
   Microsoft Azure is recommended for organizations heavily invested in Microsoft technologies. It provides seamless native integration with Active Directory (Entra ID), Windows Server, Office 365, and SQL Server, which simplifies licensing and architecture migration.

3. **Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**  
   Google Cloud Platform (GCP) is widely recognized for AI/ML and Kubernetes. Google pioneered Kubernetes (introducing GKE) and has developed industry-leading AI infrastructure like Tensor Processing Units (TPUs) and TensorFlow.

4. **What similarities did you observe among the three cloud providers?**  
   All three major cloud providers rely on the same fundamental pillars: scalable virtual compute instances, object and block storage solutions, isolated virtual networks, and granular identity/access management controls to secure resources.
